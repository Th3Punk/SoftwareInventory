# Dokumentáció böngészése

A SoftwareInventory minden alkalmazáshoz többféle dokumentációt tárol, amelyek jogosultságodnak megfelelően érhetők el.

## Dokumentáció típusok

| Típus | Tartalom | Ki látja? |
|-------|----------|-----------|
| **Felhasználói** | Funkciók, elérhetőség, kapcsolattartók | Minden bejelentkezett felhasználó |
| **Fejlesztői** | API, konfiguráció, deploy, ADR | Fejlesztők és adminisztrátorok |
| **Üzemeltetési** | Runbookok, riasztáskezelés | Kizárólag adminisztrátorok |

## Dokumentum megtekintése

1. Keresd meg az alkalmazást a katalógusban.
2. Kattints az alkalmazás nevére a részletes nézet megnyitásához.
3. A **Dokumentáció** szekcióban találod a számodra elérhető dokumentumokat.

## Verzióhistory

Minden módosítás előtt az előző verzió automatikusan archiválódik. A korábbi verziók megtekintéséhez fejlesztői vagy adminisztrátori jogosultság szükséges.

## Dokumentum szerkesztése

A dokumentumok szerkesztéséhez fejlesztői vagy adminisztrátori szerepkör szükséges. A szerkesztő felület Markdown formátumot használ (fejlécek, listák, kódblokkok, táblázatok támogatottak).

> **Méretkorlát:** Egy dokumentum maximum 500 KB lehet.
